# Rokae+ 插件技能

三份技能相互独立。每份技能只完成自身范围内的工作。缺少输入时停止并说明缺失项。

| 技能 | 作用 | 输入 | 输出 |
|---|---|---|---|
| `preparing-client-plugin` | 在尚无插件工程的目录中初始化最简工程；按位置将页面挂载到中心页、底部状态栏、右侧扩展窗或物理按键 | 插件名、开发包（xCorePlugin）；挂载时还需要页面与目标位置 | 最简工程；`init()` 中的挂载调用 |
| `compiling-rokae-plugin` | 按编译环境编译客户端插件或控制器插件 | 插件名、运行平台、编译器路径；客户端另需 `qmake` 与开发包。Linux 上路径未给出时，由查找脚本列出候选并经用户确认 | 插件库的绝对路径 |
| `packaging-rokae-plugin` | 制作插件包。可只含客户端插件、只含控制器插件，或同时包含客户端插件和控制器插件。可在 Windows 和 Linux 上打包 | 打包工作目录和插件库。插件名取插件库文件名，去掉 `.dll` 或 `.so`。没有插件库文件时由用户给出插件名 | 插件包 zip 的绝对路径。包内为 `client.zip`、`controller.zip`，或同时包含这两个数据包 |

## 边界

- `preparing-client-plugin` 不编译，不打包，不写业务接口。
- `compiling-rokae-plugin` 不制作插件包，不新建客户端插件工程。
- `packaging-rokae-plugin` 不编译，不新建客户端插件工程。
- 同一句提示包含多项工作时，按所属技能依次调用。每份技能做完自己的部分后继续下一份，不在当前技能里代做另一份的工作。
